# Физические модели звуков природы

Библиотека процедурных моделей в `core/src/sources/`: ветер, листва (деревья, трава, тростник), вода, дождь, гром, а также костёр и насекомые. Ни одна модель не проигрывает записи: каждый звук синтезируется из физики источника, и каждый параметр имеет физический смысл (м/с, мм/ч, °C, м), поэтому сцена меняется вместе с окружением: «пошёл дождь» → нарастает шум дождя, мокнут и тускнеют листья, после дождя ещё долго капает с крон, похолодало → сверчки стрекочут реже.

```
                 параметры UI / сцены (WIND, RAIN мм/ч, TEMPERATURE, HUMIDITY, STORM, час)
                                       │
                             director::Weather  (накопители воды, молнии)
                                       │  Ambient (м/с, мм/ч, °C, влажность листьев/почвы, капель…)
                                       ▼
   Controls { gust (поле порывов), water (WATER), env: Ambient, … } ──► Generator::render(out)
                                       │
   scene.rs: эмиттеры ссылаются на модель + пресет + переопределения параметров
```

## Общие принципы

* **Конфиг каждой модели** — структура с полями в физических единицах (serde, `deny_unknown_fields`), метод `validate()` с допустимыми диапазонами, **именованные пресеты** (`Water::brook_pebbles()`, `Rain::light_drizzle()`, `Foliage::aspen()`…) и `PRESETS` со списком имён.
* **Смена параметров без щелчков**: `set_config()` на лету; уровни линейно интерполируются по сэмплам (`Ramp`), скорости и частоты сглаживаются (`Smooth`), события (капли, пузырьки, столкновения) просто начинают рождаться с новыми параметрами. Тест `parameter_changes_glide_without_clicks` проверяет, что резкое переключение пресета не даёт скачков больше обычных.
* **Реальное время**: никаких аллокаций и блокировок в `render` — фиксированные пулы (`GrainPool<N>`, `BubbleBank<N>`), всё рендерится блоками по 64 сэмпла (каждое зерно/пузырёк обрабатывается целым блоком — так в 2–3 раза быстрее, чем посэмплово). Тяжёлая математика распределений (бисекция диаметра, интегралы энергии) пересчитывается только при заметном изменении входов. Денормалы гасятся (`flush`), тест проверяет отсутствие NaN/субнормальных чисел.
* **Отдельные события + ложе (теорема Кэмпбелла).** Капель, пузырьков, столкновений листьев может быть сотни тысяч в секунду. Модель рендерит отдельно не больше бюджета (`resolved_per_s`), выбирая самые крупные/громкие, а энергию остальных отдаёт шумовому «ложу» с тем же спектром: поток пуассоновских импульсов интенсивности λ с энергией E в пределе — гауссов шум мощности λ·E. Поэтому близкий маленький участок звучит отдельными каплями, а большой далёкий — ровным шумом, из одной и той же физики. Тест `bed_and_individual_events_carry_the_same_energy` проверяет, что уровень не зависит от бюджета (±2 дБ).
* **Детерминизм**: всё случайное — из `Rng` с сидом эмиттера; одинаковый сид → одинаковый сигнал (тест).
* **Уровни** — линейная амплитуда в 1 м от источника (дальше распространение делает движок). Отношения уровней физические, кроме явно оговорённых `gain`-подрезок громких режимов (пороги, водопад) под запас микса.

## Связь с окружением

### Параметры (C ABI, `asmr.h`)

| Параметр | Единицы | Что делает |
|---|---|---|
| `ASMR_PARAM_WIND = 1` | 0..1 | Средний ветер; `wind_speed_ms(x) = 16·x^1.5` м/с на уровне крон (0.45 → 4.8 м/с, 1 → 16 м/с). Поле порывов в тех же единицах, поэтому локальная скорость у каждого эмиттера = `wind_speed_ms(gust)` |
| `ASMR_PARAM_WATER = 3` | 0..1 | Расход реки (макро `water.flow`): 0.6 = как в сцене, Q = (x/0.6)² |
| `ASMR_PARAM_TIME_OF_DAY = 9` | ч | Активность насекомых |
| `ASMR_PARAM_RAIN = 16` | мм/ч, 0..200 | Интенсивность дождя на открытом месте: 0.5 морось, 4 обычный, 15 сильный, 50 ливень |
| `ASMR_PARAM_TEMPERATURE = 17` | °C | Ритм насекомых, испарение, скорость звука |
| `ASMR_PARAM_HUMIDITY = 18` | 0..1 | Высыхание листьев и почвы |
| `ASMR_PARAM_STORM = 19` | 0..1 | Частота и близость молний (1 → ~4 удара в минуту, центр грозы ~1.5 км) |

Телеметрия: `ASMR_TELEMETRY_RAIN_RATE = 8` (фактический дождь, мм/ч), `WETNESS = 9` (мокрость листьев), `LIGHTNING = 10` (вспышка 0..1 — гром придёт через r/343 с!), `DRIP = 11` (капель с крон, мм/ч). Виды источников: `ASMR_SOURCE_RAIN = 3, THUNDER = 4, FIRE = 5, INSECT = 6`; объект `ASMR_OBJECT_SOURCE = 3`.

### `director::Weather` → `Ambient`

Каждый блок режиссёр шагает погоду и записывает `Ambient` в `controls.env` каждого эмиттера:

* **Дождь** сглаживается (нарастание ~5 с, стихание ~4 с) и колеблется как проходящие дождевые ячейки (Орнштейн–Уленбек, ~20 с, ±30 %).
* **Вода в кроне** — модель Раттера (Rutter et al. 1971): `dC/dt = (1−p)·R − D − E`, свободное просачивание p = 0.25, ёмкость S = 1.2 мм, сток `D = D_s·e^{b(C−S)}` (D_s = 0.12 мм/ч, b = 3.7 мм⁻¹) плюс стряхивание ветром ∝ C·(U/5)², испарение `E = E_pot·C/S`, `E_pot = 0.45·VPD·(1+0.5U)` мм/ч (VPD — дефицит давления пара по Тетенсу). Сток D и есть капель с крон: в ливень он ≈ перехвату, после дождя затухает десятки минут, порыв ветра стряхивает «душ» капель. `leaf_wetness = C/S`.
* **Почва**: поверхностная вода (дождь + капель − инфильтрация ~4 мм/ч − испарение) и медленная влажность почвы; лужи появляются, когда слой воды > 1 мм.
* **Молнии**: пуассоновские удары с частотой ∝ STORM, на расстоянии вокруг центра грозы (12 км·(1−storm)+1.5 км, лог-нормальный разброс), азимут центра медленно дрейфует. Режиссёр ставит эмиттер грома в направлении удара на 40 м (`THUNDER_PROXY_M`) и увеличивает счётчик `env.strike`.
* **Сезон** (`environment.season`): сухость листьев 0 (весна) / 0.1 (лето) / 0.85 (осень) / 1, листва на лиственных 0.8 / 1 / 0.75 / 0.05 (зима).
* `environment.weather_time_scale` ускоряет только накопители воды (демо: час высыхания за минуту).
* Сила дождя (`rain_unit(мм/ч)`) также приглушает птиц (как раньше `rain` 0..1).

Цепочка «пошёл дождь»: RAIN 0 → 12 мм/ч ⇒ дождевые участки звучат через ~5 с (крупные капли отдельно, мелкие ложем) ⇒ кроны набирают воду, `leaf_wetness` ↑ ⇒ шелест становится глуше и реже (мокрые листья тяжёлые и слипаются), удары по листьям — ниже ⇒ почва мокнет: глухие удары по земле сменяются шлепками, затем каплями в лужах (с пузырьками) ⇒ насекомые замолкают ⇒ RAIN → 0: дождь стихает, а капель под деревьями продолжается и редеет; порыв ветра стряхивает новую порцию.

## Модели

### Ветер (`model: "wind"`)

Звука «воздуха» нет — слышно обтекание препятствий.

* **Тело**: срыв вихрей с цилиндров диаметра d на частоте f = St·U/d (St ≈ 0.2), дипольное излучение I ∝ U⁶ (Phillips 1956). В растительности диаметры от хвоинок до стволов; по правилу Леонардо (N(d) ∝ d⁻², длина ∝ d) вклад каждой логарифмической полосы диаметров примерно одинаков — отсюда широкий «рёв». Модель: 6 шумовых полос на St·U/dₖ, расширенных турбулентностью (Q ≈ 1.3), с порогом Re > 40 и порогом слышимости. Гибкая растительность «складывается» (сопротивление ∝ U^1.3, Vogel 1989), поэтому закон уровня по умолчанию I ∝ U^4.6; выше 12 м/с рост уровня замедляется (потеря когерентности срыва).
* **Эоловы тона** проводов: срыв синхронизируется с поперечными модами провода fₙ = n·f₁ («эолова арфа») — звучит мода, ближайшая к St·U/d, и при изменении ветра тон перескакивает между гармониками. Длинные ЛЭП (f₁ ≈ 1 Гц) дают гул с биениями, следующий за St·U/d.
* **Щели и дупла**: слой сдвига над отверстием длины L колеблется на частотах Росситера f ≈ 0.57·(m−¼)·U/L; когда одна из них совпадает с резонансом Гельмгольца полости, щель свистит или воет — вой появляется и пропадает с порывами.
* **Дальний ветер**: усреднение порывов по площади (сглаживание ∝ расстоянию) и потеря высоких частот (поглощение в воздухе).

### Листва (`model: "foliage"`)

* **Лиственные**: лист трепещет с частотой f ≈ St_лист·U/c (c — ширина листа, St ≈ 0.12) после видового порога скорости; соседние листья сталкиваются, каждое столкновение — короткий шумовой импульс, полоса и длина которого зависят от размера и состояния листа: свежие мягко шуршат (2–4 кГц), сухие осенние жёсткие — трещат (ярко, коротко, многократные щелчки), мокрые тяжёлые и слипаются (реже, глуше, длиннее). Частота столкновений ∝ число листьев × частота трепетания × вовлечённость(U), сила ∝ U. **Осина**: сплюснутые черешки — трепещет при едва заметном ветре, группами в фазе — её «аплодисменты».
* **Хвоя** не сталкивается: сосна «вздыхает» эоловым срывом с облака хвоинок, каждая на St·U/d (d ≈ 1–2 мм) — шипение около 0.2·U/d, повышающееся с ветром (≈ 800 Гц при 5 м/с для ели).
* **Трава** — трение травинок, высокое плотное шипение с волнами порывов по полю (honami, длина волны ~2 м); **тростник** добавляет стук полых стеблей и низкие эоловы тона.
* **Скрип ветвей**: ствол качается как затухающий осциллятор на собственной частоте под действием порывов; при большой скорости качания трущиеся ветви дают stick-slip — серию импульсов с частотой ∝ скорости скольжения через резонансы древесины.
* **Дождь по кроне** (перехваченная доля) и капель с верхних листьев на нижние.

### Вода (`model: "water"`)

Почти всё, что мы слышим от воды, — звон пузырьков на резонансе Миннарта в момент захвата воздуха: затухающая синусоида f₀ = 3.26/r, затухание d = 0.043·f₀ + 0.0014·f₀^1.5, частота растёт f(t) = f₀(1 + ξ·d·t) (van den Doel 2005). Режимы получаются из нескольких физических параметров, а не отдельными ветками кода:

* **Захват воздуха** — где турбулентные пульсации u′ ломают поверхность: u′ растёт со скоростью, с крупностью камней относительно глубины и с турбулентностью (ступени, сужения). Ниже u′ ≈ 0.05 м/с поверхность гладкая (медленная глубокая река лишь изредка булькает у коряг).
* **Размеры пузырьков** — ломаный степенной закон, измеренный под обрушивающимися волнами (Deane & Stokes 2002): N(r) ∝ r^−3/2 ниже масштаба Хинце a_H и ∝ r^−10/3 выше, a_H = 0.5·(We_c·σ/ρ)^{3/5}·ε^{−2/5}, ε ≈ u′³/L. Спокойный ручей сохраняет крупные пузырьки («буль»), бурный порог их дробит (яркое шипение). Верхняя граница растёт с размером камней; логнормальное дрожание сглаживает края распределения.
* **Падающая струя** (ступени, водопад): шум удара мощностью ½ρQv², v = √(2gH+U²), и колебания облаков пузырьков на частотах ниже отдельных пузырьков: облако радиуса R с объёмной долей β звенит около (1/2πR)·√(3γp₀/ρβ) — десятки Гц, «гул» водопада.
* **Плеск на берегу озера**: ветровые волны на пике спектра JONSWAP f_p = 3.5·(g/U)·(gF/U²)^−0.33 с высотой H ∝ U²/g·√(gF/U²) накатывают на камни — всплеск, пачка мелких пузырьков, иногда «глоток» большого воздушного кармана, шорох отката по гальке.
* **Капли в водоём** — удар и один крупный «поющий» пузырёк («плинк»); **струйка** распадается на капли с частотой Рэлея–Плато U/(4.5·d).
* Дождь по поверхности воды.

**Река в сцене.**
* Сила потока и характер звука управляются раздельно: макро WATER — это расход Q; скорость, глубина и ширина следуют за ним по гидравлической геометрии Леопольда–Маддока (v ∝ Q^0.34, h ∝ Q^0.40, w ∝ Q^0.26), а характер (крупность камней, аэрация, турбулентность, режим-пресет) задаётся отдельно (см. «Controls ABI»).
* Перекаты и плёсы: сегменты реки детерминированно чередуются (шаг ~6 ширин русла) — на мелких перекатах с крупными камнями вода журчит, глубокие плёсы почти молчат (разброс уровней сегментов ~25 дБ).

### Дождь (`model: "rain"`)

* **Распределение капель** (Marshall & Palmer 1948): N(D) = N₀·e^{−ΛD}, N₀ = 8000 м⁻³мм⁻¹, Λ = 4.1·R^−0.21. **Скорость падения** (Atlas et al. 1973): v = 9.65 − 10.3·e^{−0.6D} м/с. Поток капель на м² — ∫N(D)·v(D)dD (замкнутая форма); при 1 мм/ч это тысячи капель на м² в секунду, почти все крошечные и тихие, звук делают немногие крупные.
* **Удар** — короткий шумовой импульс + структурная мода поверхности, амплитуда ∝ (D·v)^1.5; полоса, длина и уровень зависят от поверхности и её мокрости. На воде капли 0.8–1.1 мм почти всегда захватывают пузырёк ~0.22 мм (~14 кГц, «тип I» Pumphrey & Crum), капли > 2.2 мм иногда захватывают крупный.
* **Поверхности**: `leaves`, `needles`, `grass`, `soil` (глухо сухая, шлепки мокрая), `litter` (подстилка: хрустит сухая), `rock` (щелчок + брызги), `water`, `puddle`, `roof` (жесть: звенящие моды пластины), `wood`, `snow`. На земле по мере намокания появляются лужи (`env.puddles`) — часть капель попадает в воду.
* **Капель с крон**: капли ~4.8 мм, падающие с `drip_height_m`, скорость v = v_t·√(1 − e^{−2gh/v_t²}); число = сток кроны (мм/ч) × площадь / объём капли (≈ 4.8 капли/с на м² при 1 мм/ч).
* Диффузный фон и отдельные капли — из одной модели (бюджет + ложе).

### Гром (`model: "thunder"`)

* Канал — трёхмерное случайное блуждание от точки удара до основания облака (сегменты ~8 м, средний излом ~16°, Few 1969; Ribner & Roy 1982), плюс боковые ветви и внутриоблачная горизонтальная часть.
* Каждый сегмент излучает слабую ударную N-волну; её длина задаётся радиусом релаксации Фью R₀ = √(E_l/(π·p₀)) (E_l ~10⁵–10⁶ Дж/м), доминирующая частота ≈ 0.63·c/R₀ (100–200 Гц у канала); с расстоянием N-волна медленно удлиняется (∝ r^¼).
* Излучение сильнее поперёк сегмента: канал, видимый сбоку, даёт удар, видимый с торца — долгий раскат.
* Время прихода r/c растягивает импульсы на секунды: ближняя часть канала приходит первой (треск близкого удара), дальняя — позже (раскат). Сферическое расхождение и поглощение воздухом (срез ~5 дБ/км на 1 кГц) делают дальний гром низким рокотом без треска; дальше ~20 км — акустическая тень (рефракция вверх). Турбулентность рассеивает часть каждого импульса в «коду», растущую с расстоянием; эхо от рельефа и опушек — задержанные тёмные копии.
* Звук начинается через r/c после вспышки (3 с на км): `LIGHTNING` в телеметрии мигает сразу, гром — позже.
* Эмиттер — «указатель направления» в 40 м (режиссёр ставит его в сторону удара), дальняя физика считается внутри; движок компенсирует 1/r прокси (`THUNDER_GAIN`).

Параметры: `cloud_base_m` 500..8000, `tortuosity_deg` 3..45, `segment_m` 3..60, `energy_j_per_m` 1e4..5e6, `branches` 0..12, `intracloud` 0..1, `distance_m` (<0 — удары режиссёра, иначе фиксированное расстояние) и `interval_s`, `gain`. Пресеты: `storm` (по режиссёру), `close_strike`, `summer_storm`, `distant_rumble`, `rolling`.

### Костёр (`model: "fire"`)

* **Гул**: шум турбулентного диффузионного пламени — низкочастотный (пик ~100–300 Гц, ниже у большого огня), мощность ∝ тепловыделению; пламя «пыхает» с частотой мерцания f ≈ 1.5/√D Гц (Cetegen & Ahmed 1993). Ветер раздувает огонь.
* **Треск**: вода и смола в древесине вскипают и рвут стенки клеток. Хлопки кластеризуются (один разрыв открывает следующий) — самовозбуждающийся процесс Хокса с коэффициентом ветвления < 1; базовая частота максимальна при умеренной влажности топлива (слишком сухое — мало пара, слишком сырое — тлеет); сила хлопков логнормальная (редкие громкие «выстрелы»).
* **Шипение** пара из торцов сырых поленьев, эпизодами; **угли** оседают — глухие удары и стеклянный звон; **дождь по углям** — короткое шипение каждой капли.

Параметры: `heat_kw` 1..2000, `diameter_m` 0.1..5, `moisture` 0.02..0.6, `resin` 0..1, `embers` 0..1, `gain`. Пресеты: `campfire`, `bonfire`, `wet_wood`, `resinous_pine`, `embers`.

### Насекомые (`model: "insects"`)

* **Сверчки**: при закрывании крыльев скребок идёт по зубчатой «пилке»; механизм-«спуск» делает частоту ударов зубцов равной резонансу «арфы» крыла, поэтому каждый слог — почти чистый тон (полевой сверчок ~4.5 кГц), слегка понижающийся к концу хода. Слоги складываются в трели-чирики.
* **Древесный сверчок** (Oecanthus fultoni) — термометр Долбера (1897): N/мин = 4·T_F − 160 = 7.2·T_C − 32; соседи синхронизируются (связь Курамото).
* **Кузнечики-певчие** (Tettigoniidae): длинные серии широкополосных высоких слогов ночью; **кобылки** трут зубчики бедра о жилку крыла — жужжащие шумовые эхемы днём на солнце.
* **Цикады**: изгиб рёбер тимбала — щелчок, звонящий в резонаторе брюшка (~5 кГц), сотни импульсов в секунду, длинные крещендо в жару.
* Все ритмы линейны по температуре (Q₁₀ ≈ 2 ≈ 4–5 %/°C около 20 °C); у вида есть порог температуры, часы активности; дождь и сильный ветер их глушат.

Параметры: `kind` (field_cricket / tree_cricket / bush_cricket / grasshopper / cicada), `count` 1..12, `carrier_hz`, `min_temp_c`, `active_from_h`/`active_to_h`, `temperature_offset_c` (микроклимат: солнечный луг +3), `synchrony`, `spread`, `gain`. Пресеты: `field_cricket`, `tree_cricket`, `bush_cricket`, `grasshopper`, `cicada`.

## Controls ABI (ветвящиеся слайдеры)

`asmr_get_controls` отдаёт дерево контролов: у каждой звуковой группы один **макро**-слайдер, его **дети** — физические параметры моделей. Структура `AsmrControlInfo` (asmr.h): `id` (стабильный), `group`, `parent` (id макро или `UINT32_MAX`), `flags` (bit0 макро, bit1 логарифмический, bit2 дискретный индекс пресета, bit3 ребёнок задан пользователем), `min/max/value/default_value`, `key` («water.depth»), `unit`.

* Движение макро двигает детей по физической кривой, пока пользователь не задал ребёнка явно; `asmr_set_control(id, NAN)` возвращает ребёнка макро.
* Пресеты — дискретные дети: индекс 0 = «как в сцене», имена — `asmr_get_control_option(engine, id, index, buf, max)`.
* Старые параметры и есть макро (одно хранилище): WATER ↔ `water.flow`, WIND ↔ `wind.speed` (в контроле м/с), RAIN ↔ `rain.rate`, STORM ↔ `rain.storm`, BIRDS/ORBIT ↔ `birds.*`, VOLUME ↔ `master.volume`, TIME_OF_DAY/TEMPERATURE/HUMIDITY ↔ `env.*`. `asmr_set_param` для STORM/TEMPERATURE/HUMIDITY помечает соответствующего ребёнка как явно заданного; текущее приложение работает без изменений.
* Без блокировок: значения в атомиках; аудиопоток раз в блок берёт снимок и, если он изменился, перенастраивает генераторы (`Generator::set_model`, копирование POD-конфигов, без аллокаций). Конфиги применяются относительно построенных (вариация сегментов реки сохраняется).

## Производительность

M5 Max, 48 кГц, блоки по 64 сэмпла, один поток; `cargo run --release --example models -- bench` и `-- scene` (полная таблица — в выводе `bench`).

На экземпляр, в «своей» погоде (% одного ядра): ветер 0.06–0.15, листва 0.08–0.2, вода 0.02–0.3 (пороги/водопад больше всего), участок дождя 0.1–0.2 (жестяная крыша 0.22), костёр 0.08–0.1, насекомые 0.02–0.03, гром 0.01 в паузах и до ~0.4 во время раската. Все 58 пресетов одновременно — ~5.6 %.

Генераторы всей сцены по умолчанию (43 эмиттера, без распространения и бинаурала):

| Условия | CPU одного ядра |
|---|---|
| сухо, ветер 4.8 м/с, 09:00 | 1.8 % |
| сумерки, сверчки | 1.6 % |
| ливень 15 мм/ч, гроза, ветер 8.8 м/с, капель с крон | 4.8 % |

Полная нагрузка движка (`ASMR_TELEMETRY_DSP_LOAD`: генераторы + распространение + бинаурал) в демо `weather`: 2.5–3.5 % в сухую погоду, 5–6.7 % в ливень с грозой. Для сравнения: та же сцена до этой работы (23 эмиттера, без погоды) — 2.0 %. Цифры шумят на ±0.5 %, если машину нагружают другие процессы.

Что сделано для бюджета: поблочный рендер зёрен и пузырьков (каждый в своём цикле по блоку), собственный LCG-шум у зерна, кэширование распределения капель (пересчёт только при изменении входов на 2–5 %), ложе вместо лишних событий, ранний выход у молчащих генераторов. Резерв на будущее: SIMD по зёрнам, меньший `resolved_per_s` у далёких участков, общие шумовые ложа у соседних эмиттеров.

## Демо

```bash
cargo run --release --manifest-path core/Cargo.toml --example models -- presets renders/presets.wav   # все пресеты подряд
cargo run --release --manifest-path core/Cargo.toml --example render -- 150 renders/weather_change.wav weather
```

`weather`: сцена по умолчанию в 20:30 — штиль, сверчки (0–20 с) → ветер усиливается до 12 м/с (20–45 с) → гроза, ливень до ~15–20 мм/ч, холодает 22 → 15 °C (45–100 с) → дождь кончается, кроны продолжают капать (капель 3–4 мм/ч сразу после дождя, ~1 мм/ч через 50 с при ускорении накопителей ×20), порыв на 120 с стряхивает капли, сверчки возвращаются — реже. Каждые 5 с печатаются погода, уровни по видам источников и нагрузка; `levels` — то же без сценария. Демо всех пресетов нормализует громкость каждого (физический уровень в 1 м печатается рядом).
