# Режиссёр сцены (director)

Режиссёр решает, **что есть в сцене, где находится каждый звучащий объект и как он себя ведёт во времени**. Физика звука (генераторы, распространение, Ambisonics, бинаурал) ничего не знает о птицах и деревьях: она получает от режиссёра набор эмиттеров с позициями и управляющими значениями на каждый блок.

```
SceneDesc (JSON) ──► World::build ──► World (граф сцены) ◄──┐
   данные, валидация      │             сущности + эмиттеры   │ позиции птиц, controls
                          └──► Director::new ──► Director ────┘ каждый блок (64 сэмпла)
                                                     ▲
                Environment: час, BIRDS, ORBIT, дождь│
                                                     │
engine.rs: apply_moves (UI) → director.step → world.update_emitters → для каждого эмиттера:
           generator.render(controls) → propagate(path, rel, gain, signal, bus) → бинаурал
```

## Граф сцены

- **Сущность** (`Entity`): стабильный `u32` id, вид (`tree` / `river` / `bird`), позиция, геометрия, флаги, диапазон своих эмиттеров.
- **Эмиттер** (`Emitter`): владелец, смещение относительно владельца, генератор (`Box<dyn Generator>`), управляющие значения. Позиция эмиттера каждый блок выводится из позиции владельца, поэтому:
  - дерево владеет эмиттером ветра/листвы в кроне (`position + (0, 0, canopy_height)`); сдвинули дерево — сдвинулся шелест и сидящие на нём птицы;
  - река владеет N эмиттерами-сегментами, равномерно по длине полилинии; полилиния хранится относительно центроида, сдвиг реки = перенос полилинии;
  - птица владеет одним эмиттером `Flyer` (голос + крылья в одной точке).
- Координаты движка: голова слушателя в начале координат, +x вперёд, +y влево, +z вверх, метры. Земля на `environment.ground_z` (по умолчанию −1.7 м: уши на высоте 1.7 м). Позиция дерева = основание ствола.

## Формат описания сцены (JSON)

Строгая схема: неизвестные поля, неизвестные виды, повторяющиеся id, ссылки на несуществующие деревья — ошибка (`World::build` возвращает `Err` с текстом, пригодным для возврата LLM на исправление).

```jsonc
{
  "name": "Forest by the river",
  "seed": 3000,                       // все случайные решения детерминированы сидом
  "environment": {
    "time_of_day": 9.0,               // часы 0..24 → ASMR_PARAM_TIME_OF_DAY
    "season": "summer",               // spring|summer|autumn|winter (пока заглушка)
    "rain": 0.0,                      // 0..1 (заглушка: птицы меньше поют и летают)
    "wind": 0.45, "birds": 0.6, "water": 0.6,   // необязательно: стартовые значения слайдеров
    "ground_z": -1.7
  },
  "director": { "flock_interval": [60, 150], "first_flock": 30 },
  "entities": [
    { "kind": "river", "id": 50, "path": [[4,-10,-1.2], [3.6,0,-1.2], [4.1,10,-1.2]],
      "flow": 1.0, "segments": 5, "bubble_rate": 350 },
    { "kind": "tree", "id": 2, "species": "birch", "position": [1.5, 6.8, -1.7],
      "canopy_height": 6.2, "canopy_radius": 2.0 },
    { "kind": "bird", "id": 100, "species": "chaffinch", "loudness": 1.0, "pitch": 4300, "tempo": 1.0,
      "behaviour": { "type": "resident", "home": 2, "roam": 1.0, "orbit": true } }
  ]
}
```

Деревья: `birch | oak | spruce | willow | alder` (тембр шелеста). Виды птиц: `chaffinch | robin | song_thrush | nightingale | tawny_owl | cuckoo | wood_pigeon | swallow`. Поля с умолчаниями можно опускать; `id` тоже (тогда `1000 + индекс`), но для UI и промптов лучше задавать.

## Поведения

Все агенты работают в аудиопотоке на контрольной частоте (750 Гц при 48 кГц), без аллокаций: пути — кубические Безье с опорными точками внутри состояния, маршруты — массив фиксированной длины.

| `behaviour.type` | Что происходит | Параметры |
|---|---|---|
| `resident` | Сидит на дереве и поёт → (если не спит в этот час) взлетает → летит по дуге (Безье, плавный разгон/торможение) → садится на **другое** дерево. Взлёт — хлопанье крыльев, в полёте контактные позывки, при посадке трепетание. Ночью дневные птицы не летают. | `home` (id дерева), `roam` (частота перелётов), `orbit` (слайдер ORBIT заставляет её кружить вокруг головы, при ORBIT=0 возвращается на дерево) |
| `flyby` | Вне сцены → пролёт по почти прямой мимо головы на расстоянии `min_distance` с пением/позывками → улетает. Слышно приближение, переход справа налево (или наоборот) и удаление. | `first`, `interval`, `speed`, `min_distance`, `height`, `reach` |
| `circle` | Прилетает, делает `laps` кругов вокруг `center` (по умолчанию — голова слушателя), улетает или садится на `home`. | `center`, `radius`, `height`, `speed`, `laps`, `first`, `interval`, `home` |
| `approach` | Появляется далеко (`far`), приближается перелётами (`hops`), на каждой остановке поёт, дольше всего — рядом (`near`); затем удаляется в другом направлении и исчезает. | `first`, `interval`, `far`, `near`, `hops`, `linger`, `speed` |
| событие «стая» (`director`) | Несколько `resident`-птиц, сидящих на одном дереве, почти одновременно (разброс 0–0.8 с) взлетают и перелетают на дальнее дерево. | `flock_interval`, `first_flock` |

Состояния агента: `Perched(anchor) → Flying(bezier, then) → Perched | Circling | Absent`. Якорь `Tree{tree, offset}` следует за деревом, если его двигает пользователь (и в полёте конечная точка тоже пересчитывается).

## Время суток и виды

`ASMR_PARAM_TIME_OF_DAY` (часы) читается каждый блок. Для каждого вида в `species.rs` задана почасовая кривая активности пения (24 значения с интерполяцией) и признак ночного полёта:

- **рассвет (≈04–07)** — dawn chorus: зяблик, зарянка, певчий дрозд, кукушка на максимуме;
- **день** — умеренно; ласточки активны, голубь воркует;
- **сумерки (≈19–22)** — зарянка и дрозд снова громче, просыпается неясыть;
- **ночь** — соловей и неясыть (`tawny_owl`) поют, дневные птицы молчат и не летают; сова летает бесшумно.

Активность голоса = кривая вида × (BIRDS / 0.6) × (1 − 0.8·дождь). Пролёты/подлёты/круги запускаются только если вид не спит в этот час; выступающая птица поёт не меньше чем на 0.6. Время пока не течёт само; его выставляет UI (или будущий «ход времени»).

## Голоса: интерфейс для нейросетей

```rust
pub trait Generator: Send {
    fn render(&mut self, out: &mut [f32], controls: &Controls);  // аудиопоток, без аллокаций
    fn pitch(&self) -> f32 { 0.0 }       // телеметрия: текущая высота
    fn event_rate(&self) -> f32 { 0.0 }  // телеметрия: пузырьки/с и т.п.
}
pub struct Controls { water, gust, activity, calling, flap }
```

Режиссёр пишет `activity` (насколько охотно петь, 0 = молчать), `calling` (короткие позывки вместо песни) и `flap` (усилие крыльев); движок — `water` и `gust`. Процедурный голос (`sources::Bird`) сам строит фразы по стилю вида. Нейросетевой голос просто реализует тот же `Generator` и подставляется в `Flyer::new(voice, wings, gain)` в `World::build` (одно место: ветка `EntityDesc::Bird`).

## Связь с UI (C ABI, только добавления)

```c
ASMR_PARAM_TIME_OF_DAY = 9                       /* часы 0..24 */
typedef struct AsmrObjectInfo { uint32_t id; uint32_t kind; float x, y, z; uint32_t flags; } AsmrObjectInfo;
uint32_t asmr_get_objects(const AsmrEngine*, AsmrObjectInfo *out, uint32_t max);
void asmr_set_object_position(const AsmrEngine*, uint32_t id, float x, float y, float z);
AsmrEngine *asmr_engine_new_with_scene(float sample_rate, const char *scene_json);   /* NULL при ошибке */
```

- `kind`: `ASMR_OBJECT_TREE=0`, `RIVER=1`, `BIRD=2`. `flags`: bit0 `MOVABLE` (деревья, реки), bit1 `MOVING` (летит сама), bit2 `ABSENT` (вне сцены — не рисовать).
- Перемещение: из любого потока, атомики на объект (без блокировок); применяется аудиопотоком в начале следующего `asmr_render` (и на паузе тоже). Птиц двигать нельзя. Позиция реки — центроид полилинии.
- `asmr_get_sources` по-прежнему отдаёт эмиттеры (теперь их 23 в сцене по умолчанию, максимум 64). Отсутствующие птицы остаются в списке с нулевым уровнем — фильтруйте по `ABSENT` из `asmr_get_objects`.

## Как сюда подключится промпт

1. **LLM → SceneDesc.** Промпт («лес у реки, 23:40, лёгкий дождь») превращается в JSON этой схемы: Claude получает схему (можно сгенерировать JSON Schema из serde-типов) и каталог видов/деревьев/поведений, выдаёт сцену; `World::build` валидирует, ошибки возвращаются модели на исправление. `time_of_day: 23.66`, `rain: 0.3`, ночные виды (`nightingale`, `tawny_owl`), реку и деревья модель выбирает сама.
2. **LLM → политика режиссёра.** Следующий шаг — сделать данными и то, что сейчас в коде: кривые активности видов, частоты событий, «сценарий» (например «через минуту стая скворцов пролетает слева»). Это расширение `DirectorDesc` (список запланированных событий и весов поведений), а не новый код.
3. **Новые типы источников** (дождь, дятел, лягушки, костёр) = новый вариант `EntityDesc` + генератор + при необходимости агент. Режиссёр и движок от этого не меняются.
4. Звуки видов, которых нет в процедурном каталоге, придут из нейросетевых голосов той же `Generator`-формы.

## Демонстрация

```bash
cargo run --release --manifest-path core/Cargo.toml --example render -- 60 renders/flyby_demo.wav flyby
```

Сцена `demo_flyby.json` (07:30, тихие река и ветер), таймлайн печатается вместе с уровнем L/R каждые 0.5 с:

| t, с | Событие |
|---|---|
| 3–9 | ласточка пролетает справа налево в 1.7 м от головы (R +5 дБ → L +8 дБ) |
| 10.6–15 | стая (3 зяблика + вяхирь) с ивы спереди-справа перелетает на дальний дуб сзади-слева |
| 14–39 | кукушка: появляется в 35 м справа, подлетает перелётами 24 → 13 → 3 м, кукует рядом, улетает вперёд и исчезает |
| 34–50 | вторая ласточка прилетает и делает два круга радиусом 3 м вокруг головы |
| 50–56 | второй пролёт ласточки; стая возвращается |

Другой файл сцены: `... --example render -- 60 out.wav flyby my_scene.json`.
