# Режиссёр сцены (director)

Режиссёр решает, **что есть в сцене, где находится каждый звучащий объект и как он себя ведёт во времени**. Физика звука (генераторы, распространение, Ambisonics, бинаурал) ничего не знает о птицах и деревьях: она получает от режиссёра набор эмиттеров с позициями и управляющими значениями на каждый блок.

```
SceneDesc (JSON) ──► World::build ──► World (граф сцены) ◄──┐
   данные, валидация      │             сущности + эмиттеры   │ позиции птиц, controls
                          └──► Director::new ──► Director ────┘ каждый блок (64 сэмпла)
                                                     ▲
                Environment: час, BIRDS, ORBIT, дождь│
                                                     │
engine.rs: apply_moves (UI) → director.step → world.update_emitters → для каждого эмиттера:
           generator.render(controls) → propagate(path, rel, gain, signal, bus) → бинаурал
```

## Граф сцены

- **Сущность** (`Entity`): стабильный `u32` id, вид (`tree` / `river` / `bird`), позиция, геометрия, флаги, диапазон своих эмиттеров.
- **Эмиттер** (`Emitter`): владелец, смещение относительно владельца, генератор (`Box<dyn Generator>`), управляющие значения. Позиция эмиттера каждый блок выводится из позиции владельца, поэтому:
  - дерево владеет эмиттером ветра/листвы в кроне (`position + (0, 0, canopy_height)`); сдвинули дерево — сдвинулся шелест и сидящие на нём птицы;
  - река владеет N эмиттерами-сегментами, равномерно по длине полилинии; полилиния хранится относительно центроида, сдвиг реки = перенос полилинии;
  - птица владеет одним эмиттером `Flyer` (голос + крылья в одной точке).
- Координаты движка: голова слушателя в начале координат, +x вперёд, +y влево, +z вверх, метры. Земля на `environment.ground_z` (по умолчанию −1.7 м: уши на высоте 1.7 м). Позиция дерева = основание ствола.

## Формат описания сцены (JSON)

Строгая схема: неизвестные поля, неизвестные виды, повторяющиеся id, ссылки на несуществующие деревья — ошибка (`World::build` возвращает `Err` с текстом, пригодным для возврата LLM на исправление).

```jsonc
{
  "name": "Forest by the river",
  "seed": 3000,                       // все случайные решения детерминированы сидом
  "environment": {
    "time_of_day": 9.0,               // часы 0..24 → ASMR_PARAM_TIME_OF_DAY
    "season": "summer",               // spring|summer|autumn|winter (пока заглушка)
    "rain_mm_h": 0.0,                 // мм/ч; погода и звуки природы: docs/physical-models.md
    "wind": 0.45, "birds": 0.6, "water": 0.6,   // необязательно: стартовые значения слайдеров
    "ground_z": -1.7
  },
  "director": { "flock_interval": [60, 150], "first_flock": 30 },
  "entities": [
    { "kind": "river", "id": 50, "path": [[4,-10,-1.2], [3.6,0,-1.2], [4.1,10,-1.2]],
      "flow": 1.0, "segments": 5, "bubble_rate": 350 },
    { "kind": "tree", "id": 2, "species": "birch", "position": [1.5, 6.8, -1.7],
      "canopy_height": 6.2, "canopy_radius": 2.0 },
    { "kind": "bird", "id": 100, "species": "chaffinch", "loudness": 1.0, "pitch": 4300, "tempo": 1.0,
      "behaviour": { "type": "resident", "home": 2, "roam": 1.0, "orbit": true } }
  ]
}
```

Деревья: `birch | oak | spruce | willow | alder | aspen | pine` (пресет кроны и земли под ней, см. docs/physical-models.md). Источники `kind: "source"` (дождь, гроза, костёр, насекомые, водопад…) описаны там же. Виды птиц: `chaffinch | robin | song_thrush | nightingale | tawny_owl | cuckoo | wood_pigeon | swallow | blackbird | skylark | gull | raven`. Поля с умолчаниями можно опускать; `id` тоже (тогда `1000 + индекс`), но для UI и промптов лучше задавать.

## Поведения

Все агенты работают в аудиопотоке на контрольной частоте (750 Гц при 48 кГц), без аллокаций: пути — кубические Безье с опорными точками внутри состояния, маршруты — массив фиксированной длины.

| `behaviour.type` | Что происходит | Параметры |
|---|---|---|
| `resident` | Живёт на своей территории вокруг дерева `home`: поёт с присад, кормится на земле, отдыхает, перелетает между присадами, ласточки кормятся в воздухе — по суточному бюджету вида (см. «Жизнь птиц»). Летает своим стилем. Ночью дневные птицы ночуют на дереве, совы — наоборот. | `home` (id дерева), `roam` (частота смен занятий и перелётов), `orbit` (слайдер ORBIT заставляет её кружить вокруг головы, при ORBIT=0 возвращается на дерево) |
| `open` | Птица открытых мест без дерева (жаворонок на лугу, чайки на берегу, ворон в горах): кормится на земле, поёт с земли или в токовом полёте, парит над участком; на деревья внутри участка садится, если вид вообще садится на деревья (чайки и жаворонки — нет). | `center` (x, y), `radius` (по умолчанию 25 м), `roam` |
| `flyby` | Вне сцены → пролёт по почти прямой мимо головы на расстоянии `min_distance` с пением/позывками → улетает. Слышно приближение, переход справа налево (или наоборот) и удаление. | `first`, `interval`, `speed`, `min_distance`, `height`, `reach` |
| `circle` | Прилетает, делает `laps` кругов вокруг `center` (по умолчанию — голова слушателя), улетает или садится на `home`. | `center`, `radius`, `height`, `speed`, `laps`, `first`, `interval`, `home` |
| `approach` | Появляется далеко (`far`), приближается перелётами (`hops`), на каждой остановке поёт, дольше всего — рядом (`near`); затем удаляется в другом направлении и исчезает. | `first`, `interval`, `far`, `near`, `hops`, `linger`, `speed` |
| событие «стая» (`director`) | Несколько `resident`-птиц, сидящих на одном дереве, почти одновременно (разброс 0–0.8 с) взлетают и перелетают на дальнее дерево. | `flock_interval`, `first_flock` |

Состояния агента: `Perched(anchor, Sing|Rest|Alert) | Ground | Flying(bezier, стиль, then) | Hawking | SongFlight | Circling | Absent`. Якорь `Tree{tree, offset}` следует за деревом, если его двигает пользователь (и в полёте конечная точка тоже пересчитывается).

## Жизнь птиц (life model)

У каждой птицы-резидента своя небольшая жизнь; режиссёр только задаёт сцену и социальные сигналы.

```
                ┌──────────── решение (бюджет по часу, территория) ───────────────┐
                ▼                                                                 │
  Perched{Sing|Rest|Alert} ──смена присады──► Flying(стиль) ──посадка──► Perched ─┤
       │    ▲  (присада)                         │   ▲                            │
       │    └──────────── вверх ─────── Ground (кормится, прыгает) ◄── вниз ──────┤
       ├──► Hawking (ласточки кормятся, чайки и ворон парят) ──► Perched|Ground ──┤
       ├──► SongFlight (жаворонок: подъём, пение в зависании, падение) ──► Ground ┘
       └──► Circling / Absent (выступления: пролёт, подлёт, круги; ORBIT)
```

**Бюджет времени.** Когда занятие кончается, птица выбирает следующее с весами по часу: пение
(суточная кривая вида), кормёжка на земле (`ground`, меньше, когда время петь), отдых, смена
присады в пределах территории (`territory`, иногда дальняя вылазка), кормёжка в воздухе
(`aerial`: ласточки, чайки, ворон; у жаворонка — токовый полёт, когда время петь). У каждой
особи свой сдвиг суточного ритма ±15 мин, поэтому рассветный хор нарастает, а не включается разом.
Ночью (для совы — днём) птица ночует: садится на дерево и не летает.

**Присады и земля.** Присада для пения — на высоте, типичной для вида (`post`: дрозды на
верхушке, зарянка и соловей внутри кроны). Кормятся на земле у своего дерева, не в реке и не у
ног слушателя; по земле прыгают (0.12 с, лёгкий взмах крыльев — слышно шуршание), дрозды
«пробежка — остановка», зяблики и голуби мелко семенят.

**Стили полёта** (`species::flight_motion`, чистая функция: её может звать и режим полёта):

| Стиль | Виды | Траектория | Взмахи (`flap`, 0 = планирование) |
|---|---|---|---|
| `Bounding` | зяблик | волнистая: подъём на взмахах, спад со сложенными крыльями, ~1.9 волны/с, ±0.18 м | 0.3 с взмахов / 0.2 с тишины |
| `Direct` | дрозды, чёрный дрозд, зарянка, соловей, кукушка | низко и прямо (дуга ниже), лёгкое покачивание | почти непрерывно, короткая пауза раз в 1.2 с |
| `Swooping` | ласточка | S-образные виражи ±2 м и нырки | мягко, планирует на внешней стороне виража |
| `Clatter` | вяхирь | хлопки крыльями на взлёте; брачный полёт: крутой подъём, хлопки наверху, планирование вниз | сильные взмахи, планирует последние 1.6 с перед посадкой |
| `Silent` | неясыть | плавные покачивания | несколько беззвучных взмахов, долгое планирование |
| `Soaring` | чайка, ворон | парение кругами (Лиссажу) на 10–25 м, мягкий крен | 1.6 с медленных взмахов из 6 с |
| `Hovering` | жаворонок | трепещущий полёт; токовый полёт до 25–50 м | частые мелкие взмахи, в конце падение со сложенными крыльями |

Взлёт всегда с усилием (`flap = 1`, у голубя — хлопки), посадка — торможение (0.85). Крылья
(`sources/wings.rs`) получают `wings_driven = true` и следуют `flap` точно, поэтому звук
взмахов и траектория совпадают: пауза в звуке — это спад волны у зяблика. Позиция птицы каждый
блок идёт в движок, пролёты слышны с Доплером и задержкой распространения.

**Перекличка соседей.** Пока поёт сосед того же вида (в пределах `hearing`), птица ждёт
(`Controls::wait`: голос не начинает фразу, но птица по-прежнему «хочет» петь, и слой микса
сохраняет её место в очереди разрешений). Когда сосед замолкает, она с вероятностью `answer`
отвечает в ближайшие 0.3–1.4 с (`Controls::reply`). Так пары зарянок, чёрных дроздов, зябликов
поют по очереди: за 4 мин на рассвете перекрытие соседей < 50 % от случайного (тест
`neighbours_take_turns_and_answer`). С ограничителем фраз в `mix` это не конфликтует: режиссёр
решает, *кто хочет* петь и когда уместно ответить, микс — *сколько* фраз звучит одновременно.

**Тревога.** `Director::disturb(at, strength, flee)` — общая точка входа; сам режиссёр вызывает
её, когда пользователь тащит дерево (его птицы тревожатся, утащили дальше 4 м за 2 с — улетают),
когда днём пролетает сова (дрозды, зяблики, зарянки окрикивают её), когда рядом с треском
взлетает голубь. Ближе `flush` вида — бегство на дальнее от опасности дерево с тревожными
криками в полёте; ближе 2.5 × `flush` — тревожные позывки с присады (птицы с земли сперва
взлетают в крону); потом 20–60 с птица поёт мало. Тревожные голоса процедурные
(`Controls::alarm`): «чик-чик» и треск чёрного дрозда, «тик» зарянки, «пинь» зяблика, «чак»
певчего дрозда, хохот чайки, «кра» ворона.

**Стаи.** Событие стаи (`flock_interval`) поднимает птиц одного дерева, склонных к стаям
(`flocking ≥ 0.2`), и ведёт их по одному общему пути к дальнему дереву с разбросом строя ±1 м и
задержкой взлёта до 0.8 с.

**Таймлайн.** `cargo run --release --example render -- 180 dawn.wav life:5.5` печатает каждую смену
занятия и сводку (доля времени по состояниям, число фраз и ответов, сколько птиц пело сразу);
`life:5.5:free` — то же без ограничителя фраз микса. Пример (сцена по умолчанию, 05:30, 180 с):

```
  60.0s  chaffinch    #106  takes off (bounding)           at   7.5 m, az   +73°, h  +4.2 m
  61.1s  chaffinch    #106  singing (8 m in 1.1 s)         at   9.6 m, az  +129°, h  +3.3 m
```

Днём (10:00) те же птицы 30–40 % времени кормятся на земле, ночью (23:30) дневные ночуют,
поют соловей и неясыть (сова изредка беззвучно перелетает). `open_country.json` в 07:00:

кормятся над лугом.

**Цена.** `Director::step` для сцены по умолчанию (13 птиц): 0.32 мкс на блок — 0.024 % ядра;
DSP-нагрузка всей сцены не изменилась (5.5 % против 5.4 % до изменений при трёх добавленных птицах).
Всё в аудиопотоке без аллокаций: массивы состояний выделены в `Director::new`.

## Биомы

Для процедурного мира (режим полёта и будущие биомы):

```rust
use asmr_core::director::{species_weights_for_biome, bird_density_for_biome, pick_species_for_biome};
let w: &'static [(Species, f32)] = species_weights_for_biome("sea_coast"); // доли видов, сумма 1
let k: f32 = bird_density_for_biome("sea_coast");                          // численность, лес = 1
let s: Species = pick_species_for_biome("sea_coast", rng.uniform());        // детерминированный выбор
```

Без аллокаций, из любого потока. Имена без учёта регистра, `-`/пробел = `_`; неизвестное → лес.

|---|---|---|
| `forest` (по умолчанию, woodland) | зяблик .22, зарянка .15, чёрный дрозд .14, певчий дрозд .11, вяхирь .10, соловей, кукушка, ласточка, неясыть по .06, ворон .04 | 1.0 |
| `meadow` (field, steppe, grassland, heath) | жаворонок .36, ласточка .20, кукушка, зяблик .09, вяхирь .08, чёрный дрозд .07, ворон .06, зарянка .05 | 0.7 |
| `desert` (dunes, sand) | жаворонок .45, ворон .40, ласточка .15 | 0.2 |
| `snowy_mountains` (snow, mountains, alpine, tundra) | ворон .75, зарянка .15, зяблик .10 | 0.12 |
| `lake_shore` (lake, marsh, wetland) | чайка .24, ласточка .20, соловей .12, чёрный дрозд .10, зяблик .09, кукушка .08, зарянка .07, вяхирь .06, неясыть .04 | 0.85 |
| `sea_coast` (coast, sea, beach, cliffs) | чайка .70, жаворонок .12, ворон .10, ласточка .08 | 0.75 |
| `big_river` (river, floodplain) | ласточка .20, соловей, чёрный дрозд, зяблик по .12, зарянка .10, чайка .10, певчий дрозд .08, кукушка .07, вяхирь .05, неясыть .04 | 0.95 |

Птиц без деревьев (чайки, жаворонки, ворон в горах) ставьте с поведением `open`.

## Время суток и виды

`ASMR_PARAM_TIME_OF_DAY` (часы) читается каждый блок. Для каждого вида в `species.rs` задана почасовая кривая активности пения (24 значения с интерполяцией) и признак ночного полёта:

- **рассвет (≈04–07)** — dawn chorus: зяблик, зарянка, певчий дрозд, кукушка на максимуме;
- **день** — умеренно; ласточки активны, голубь воркует;
- **сумерки (≈19–22)** — зарянка и дрозд снова громче, просыпается неясыть;
- **ночь** — соловей и неясыть (`tawny_owl`) поют, дневные птицы молчат и не летают; сова летает бесшумно.

Активность голоса = кривая вида (со сдвигом особи) × (BIRDS / 0.6) × (1 − 0.8·дождь), × 0.12 на отдыхе, × 0.2 после испуга. Чёрный дрозд и жаворонок начинают ещё в темноте, раньше зяблика; чайки и ворон активны весь день. Пролёты/подлёты/круги запускаются только если вид не спит в этот час; выступающая птица поёт не меньше чем на 0.6. Время пока не течёт само; его выставляет UI (или будущий «ход времени»).

## Голоса: интерфейс для нейросетей

```rust
pub trait Generator: Send {
    fn render(&mut self, out: &mut [f32], controls: &Controls);  // аудиопоток, без аллокаций
    fn pitch(&self) -> f32 { 0.0 }       // телеметрия: текущая высота
    fn event_rate(&self) -> f32 { 0.0 }  // телеметрия: пузырьки/с и т.п.
}
pub struct Controls { water, gust, activity, calling, alarm, flap, wings_driven, reply, wait, env, neural, .. }
```

Режиссёр пишет `activity` (насколько охотно петь, 0 = молчать; пауза до следующей фразы
пересчитывается сразу, а не после прежней паузы), `calling` (короткие позывки вместо песни),
`alarm` (с `calling`: тревожные крики), `flap` (усилие крыльев, 0 = планирование) и
`wings_driven`, `reply` (ответить соседу в ближайшую секунду), `wait` (сосед поёт — не начинать);
движок — `water` и `gust`. Процедурный голос (`sources::Bird`) сам строит фразы по стилю вида. Нейросетевой голос просто реализует тот же `Generator` и подставляется в `Flyer::new(voice, wings, gain)` в `World::build` (одно место: ветка `EntityDesc::Bird`).

## Связь с UI (C ABI, только добавления)

```c
ASMR_PARAM_TIME_OF_DAY = 9                       /* часы 0..24 */
typedef struct AsmrObjectInfo { uint32_t id; uint32_t kind; float x, y, z; uint32_t flags; } AsmrObjectInfo;
uint32_t asmr_get_objects(const AsmrEngine*, AsmrObjectInfo *out, uint32_t max);
void asmr_set_object_position(const AsmrEngine*, uint32_t id, float x, float y, float z);
AsmrEngine *asmr_engine_new_with_scene(float sample_rate, const char *scene_json);   /* NULL при ошибке */
```

- `kind`: `ASMR_OBJECT_TREE=0`, `RIVER=1`, `BIRD=2`. `flags`: bit0 `MOVABLE` (деревья, реки), bit1 `MOVING` (летит сама), bit2 `ABSENT` (вне сцены — не рисовать).
- Перемещение: из любого потока, атомики на объект (без блокировок); применяется аудиопотоком в начале следующего `asmr_render` (и на паузе тоже). Птиц двигать нельзя. Позиция реки — центроид полилинии.
- `asmr_get_birds(engine, AsmrBirdInfo *out, max)`: на каждую птицу сцены — `id` (как в `asmr_get_objects`), вид `ASMR_SPECIES_*`, занятие `ASMR_BIRD_*` (отдыхает, поёт, тревожится, кормится, летит, парит, токовый полёт, кружит, отсутствует), стиль полёта `ASMR_FLIGHT_*`, текущее усилие крыльев, скорость, флаги (звучит / позывки / тревога). В режиме полёта — 0. `Stage/Birds.swift` по ним рисует размер вида, взмахи и планирование по стилю, крен в поворотах, тангаж, птицу на земле.
- `asmr_get_sources` по-прежнему отдаёт эмиттеры (46 в сцене по умолчанию, максимум 64). Отсутствующие птицы остаются в списке с нулевым уровнем — фильтруйте по `ABSENT` из `asmr_get_objects`.

## Как сюда подключится промпт

1. **LLM → SceneDesc.** Промпт («лес у реки, 23:40, лёгкий дождь») превращается в JSON этой схемы: Claude получает схему (можно сгенерировать JSON Schema из serde-типов) и каталог видов/деревьев/поведений, выдаёт сцену; `World::build` валидирует, ошибки возвращаются модели на исправление. `time_of_day: 23.66`, `rain: 0.3`, ночные виды (`nightingale`, `tawny_owl`), реку и деревья модель выбирает сама.
2. **LLM → политика режиссёра.** Следующий шаг — сделать данными и то, что сейчас в коде: кривые активности видов, частоты событий, «сценарий» (например «через минуту стая скворцов пролетает слева»). Это расширение `DirectorDesc` (список запланированных событий и весов поведений), а не новый код.
3. **Новые типы источников** (дождь, дятел, лягушки, костёр) = новый вариант `EntityDesc` + генератор + при необходимости агент. Режиссёр и движок от этого не меняются.
4. Звуки видов, которых нет в процедурном каталоге, придут из нейросетевых голосов той же `Generator`-формы.

## Демонстрация

```bash
cargo run --release --manifest-path core/Cargo.toml --example render -- 60 renders/flyby_demo.wav flyby
```

Сцена `demo_flyby.json` (07:30, тихие река и ветер), таймлайн печатается вместе с уровнем L/R каждые 0.5 с:

| t, с | Событие |
|---|---|
| 3–9 | ласточка пролетает справа налево в 1.7 м от головы (R +5 дБ → L +8 дБ) |
| 10.6–15 | стая (3 зяблика + вяхирь) с ивы спереди-справа перелетает на дальний дуб сзади-слева |
| 14–39 | кукушка: появляется в 35 м справа, подлетает перелётами 24 → 13 → 3 м, кукует рядом, улетает вперёд и исчезает |
| 34–50 | вторая ласточка прилетает и делает два круга радиусом 3 м вокруг головы |
| 50–56 | второй пролёт ласточки; стая возвращается |

Другой файл сцены: `... --example render -- 60 out.wav flyby my_scene.json`.
